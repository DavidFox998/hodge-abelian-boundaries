# Hodge

Genus study directories for the abelian-variety data in this repository.

The 200 measured Hodge (2,2)-class definitions stay in `lean/Consolidated_Abelian_Definitions.lean`: `class1_g3` … `class67_g3`, `class1_g4` … `class67_g4`, `class1_g5` … `class66_g5` (67 + 67 + 66).

`Abelian/G1_J0_26/` is the new buildable g=1 layer: the two J₀(26) factors from beal-conjecture. `G3_J0_143/`, `G4_J0_143/`, and `G5_J0_143/` are indexes for those genus counts. They do not duplicate the class definitions.
